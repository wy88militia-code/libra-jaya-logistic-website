Onboarding API Partner

Integrasikan sistem order perusahaan Anda dengan gateway logistik Libra. Setelah disetujui, PIC menerima link aktivasi satu kali untuk membuat PIN sendiri dan mengambil kredensial UAT secara aman.

Alur Aktivasi

Ajukan onboarding
Isi identitas perusahaan, PIC dan kebutuhan API.
Verifikasi Admin Libra
Admin memvalidasi perusahaan lalu membuat Partner ID dan lifecycle UAT.
Aktivasi aman
PIC menerima link satu kali, membuat PIN portal 6 digit sendiri, lalu mengambil API Key, API Secret dan Webhook Signing Secret. Secret tidak dikirim melalui chat biasa.
UAT API
Test HMAC, quote, booking dry-run, idempotency, tracking, error handling dan webhook otomatis. Booking UAT tidak memotong saldo.
Analisa & approval
Hasil log dinilai sistem dan dapat dianalisis OpenAI. Final approval tetap oleh Admin Libra.
Deposit & go-live
Deposit baru diminta setelah UAT PASS. Production API dibuka setelah saldo memenuhi minimum opening deposit.

API v1

Endpoint inti yang tersedia untuk integrasi partner:

POST /api/v1/quote
POST /api/v1/bookings
GET /api/v1/tracking?booking_id=...

Autentikasi menggunakan API Key + HMAC-SHA256. Header: x-libra-key, x-libra-timestamp, x-libra-nonce, x-libra-signature. Booking wajib x-libra-idempotency-key.

Selama UAT tambahkan x-libra-environment: UAT. Booking UAT bersifat dry-run dan tidak mendebit saldo. Setelah Production diaktifkan Admin Libra, request live menggunakan x-libra-environment: PRODUCTION atau tanpa header environment.

Webhook Callback

Isi endpoint HTTPS publik pada form. Webhook Signing Secret diterima saat aktivasi, terpisah dari API Secret. Admin Libra kemudian menjalankan test callback otomatis.

POST https://partner.example/webhooks/libra

x-libra-event
x-libra-environment
x-libra-delivery-id
x-libra-timestamp
x-libra-signature

Verifikasi signature dari timestamp + "." + delivery_id + "." + raw_body menggunakan HMAC-SHA256 + Base64URL. Header signature berbentuk v1=.... Callback dianggap berhasil bila server partner mengembalikan HTTP 2xx. Delivery gagal akan dicoba ulang otomatis.
